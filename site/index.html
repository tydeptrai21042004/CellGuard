live CKB verification

read-only RPC · no private keys or broadcast

Live verification sends the complete transaction (including witnesses) to a configured CKB RPC node via the same-origin backend. The node tests VM scripts and transaction-pool acceptance without broadcasting. Supported lock scripts may validate witness signatures; neither test guarantees inclusion or finality.
